# NutriAI Environment Setup

## Required environment variables

### Frontend

- `VITE_API_BASE_URL`
- `VITE_POWERBI_CLIENT_ID`
- `VITE_POWERBI_WORKSPACE_ID`

### Backend

- `MONGODB_URI`
- `DATABASE_NAME`
- `JWT_SECRET`
- `JWT_ALGORITHM`
- `ACCESS_TOKEN_EXPIRE_MINUTES`
- `CORS_ORIGINS`

## Example

Copy [.env.example](../../.env.example) and update the values before running the app.
